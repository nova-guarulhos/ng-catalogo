Configurar Firebase

Acesse o Firebase Console, crie um aplicativo Web e cole abaixo o objeto firebaseConfig. Esta configuração pública não é uma senha. A segurança depende das regras do Firestore e do Authentication.

Antes de publicar para funcionários, configure as regras de segurança incluídas no arquivo firestore.rules. O primeiro administrador precisa ser autorizado no Firebase Console.
